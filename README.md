## How I approach projects

- Start with a concrete workflow and build the smallest useful implementation.
- Document setup, architecture, and the limits of the current version.
- Make automated actions explicit, and provide recovery paths for stateful operations.

Explore the repositories above for source code, setup instructions, and design decisions.
