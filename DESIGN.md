# Portfolio presentation

The profile uses GitHub's native Markdown layout. Its reading order is identity → three featured projects → technical stack → current focus → contact.

Classmate leads as a public case study of a private product. TBTI Affiliate Agent supplies public full-stack source; PalRelay supplies public automation and recovery engineering. Other repositories remain available through GitHub without occupying featured space.

Each entry states product purpose, implementation scope, concrete engineering evidence, technologies, and a usable source or case-study link. Verification dates and material gaps sit beside the claims they qualify.

## Case-study layout

The Classmate case starts with product purpose and a three-screen native gallery, followed by contribution, architecture, decisions, and verification. Screenshots retain their original pixels and use descriptive alternative text. Native screenshots are explicitly dated and labeled as earlier preview states; the current web entrance is separately dated.

GitHub controls fonts, colors, spacing, and light/dark presentation. The architecture uses Mermaid with readable text labels. No external statistics widget, skill score, animated badge wall, or generated product mockup is needed to understand the work.

Legacy illustration and badge files remain in `assets/`; they are not part of the current README. Their existing provenance stays with those files. New case-study image provenance is documented in [case-studies/classmate/assets/README.md](case-studies/classmate/assets/README.md).
